# BRO: Build, Run, Operate

BRO is a practical course for those who want to move from theory to real autonomous systems.

## What this course is about

BRO focuses on the practical workflow of building, integrating, calibrating, and operating autonomous platforms.

This course aims to teach a domain-agnostic template that can transfer across air, ground, sea, and undersea systems.

## Who it is for

- anyone who wants the practical skills to make real autonomous systems

## What participants should leave with

- a clearer picture of the full system stack
- a repeatable integration workflow
- experience with real setup and debugging steps
- a better bridge from ideas to working platforms
