# FAQ

We can add to these questions as they come up during the study circle. If something is confusing during the build, setup, operation, or documentation process, that is useful feedback and can become a future FAQ entry.

## Where should I start?

For general background, start with the official ArduPilot [Introducing Copter](https://ardupilot.org/copter/docs/introduction.html) page, especially the "Getting started" section.

For the practical setup path after the hardware is selected and assembled, use ArduPilot's [First Time Setup](https://ardupilot.org/copter/docs/initial-setup.html) guide as the main reference.
