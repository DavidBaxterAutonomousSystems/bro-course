## Verification Checklist

Before relying on a file for mounts, wiring, or mechanical layout:

- Confirm it matches the actual part ordered or installed.
- Check dimensions against the physical part with calipers where possible.
- Verify hole spacing, connector clearance, cable bend radius, and orientation.
- Check whether the source provides CAD files, drawings, or only dimensions.
- Note any license or reuse restrictions before publishing derived CAD.
